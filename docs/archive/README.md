# Historical project documents

This directory contains old handoff and design documents that were useful while particular features were being developed.

They are kept for historical context only. They are **not** the current project roadmap or implementation contract, and status statements, branch names, SHAs and proposed interfaces in them may be obsolete.

Use the active documentation instead:

- `README.md` — project overview, architecture, game/version model and local setup
- `TODO.md` — current backlog and open design questions
- `AGENTS.md` — standing development and compatibility contracts
- `rezepte/README.md` — recipe authoring and verification

When an archived document conflicts with current source or active documentation, the current source and active documentation take precedence.

The archived files are intentionally not maintained as the project evolves.
